# ⚖️ Legal Document Analyzer (Hackathon Team Project)

This project was collaboratively developed as part of a **hackathon challenge**, where the goal was to create an innovative AI-powered solution for simplifying complex legal documents and improving legal accessibility.

Built through a **team collaboration**, the platform focuses on helping users better understand contracts, agreements, and legal paperwork through document analysis, risk detection, and simplified explanations.

As part of the collaborative development process, different areas of the system including frontend, backend, AI integration, and user experience were explored and improved throughout the hackathon.

This project continues to be improved beyond the hackathon phase with ongoing feature enhancements and optimizations.
## 🌐 Live Demo
🔗 **Web Application:**  
https://legal-ai-analyzer.vercel.app/

---

## ✨ Features
- AI-powered legal document analysis
- Legal document summarization
- Simplified explanations of complex legal terms
- Risk & red-flag detection
- Important clause highlighting
- Fairness analysis *(experimental)*
- User-friendly web interface
- PDF document support

## ⚠️ Important Note

The backend is hosted on **Render (Free Tier)** using Python.

Because the backend service may automatically pause after inactivity, the first request can sometimes take a little longer to respond while the server wakes up.

If the application seems unresponsive initially, please wait a few seconds and try again.
